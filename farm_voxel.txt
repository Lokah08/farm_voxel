Use the reference image named farm_voxel.png as the main visual guide.

Create a playable-looking low-poly voxel agricultural farm diorama based on farm_voxel.png.

Build the project with Vite + TypeScript + Three.js.

The goal is to recreate the layout, proportions, colors, style and object placement of farm_voxel.png as a clean 3D voxel farming-game environment.

Very important:
Do not create one single merged model.
Do not create the farm as one big static mesh.
Every visible object must be created as a separate reusable asset.
The scene must be assembled from separated assets, placed individually in the world.
Each major object should have its own creation function or module.

Visual style:
The scene must use a true low-poly voxel aesthetic:
- blocky geometry
- cubic shapes
- chunky voxel crops
- voxel trees
- voxel fences
- simple faceted forms
- colorful farming-game style
- clean isometric diorama look

Do not make the scene realistic.
Do not make it smooth or painterly.
Do not use rounded organic shapes.
Everything should feel like a polished voxel game environment.
